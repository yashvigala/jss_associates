# JSS + Associates

Portfolio site for JSS + Associates — a Mumbai architecture, interior design and
real-estate studio (est. 2020, 20+ projects, 1M+ sq.ft.).

Dark cinematic one-pager with a drag-to-orbit wireframe skyline (three.js /
react-three-fiber + bloom), a scroll-built tower sequence, a horizontal works
gallery with project lightboxes, draggable interior polaroids, and three themes —
**ink**, **blueprint** and **paper** — cycled with the nav chip or the `B` key.

## Stack

React 18 · Vite 5 · three.js / @react-three/fiber · framer-motion · lenis

## Develop

```bash
npm install
npm run dev
```

## Deploy

Pushes to `main` build and publish to GitHub Pages via
`.github/workflows/deploy.yml`.
